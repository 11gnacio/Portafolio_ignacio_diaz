# Portafolio web

Sitio estático personal, organizado por tipo de archivo:

```text
.
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── styles.css
    └── js/
        └── main.js
```

## Uso

Abre `index.html` en un navegador. No requiere instalación de dependencias ni servidor.

Antes de publicar, cambia el correo de ejemplo en la sección de contacto y personaliza el texto y los proyectos.
